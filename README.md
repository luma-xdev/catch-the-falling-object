🎯 Catch the Falling Object

A fun and interactive browser game built using HTML, CSS, and JavaScript.

🎮 Play the Game

Open the live game link and start catching falling objects!

Live Demo: Add your GitHub Pages link here after deployment.

✨ Features

- 🧺 Move the basket left and right.
- 🍎 Catch falling fruits, stars, and coins.
- 💎 Earn extra points by catching diamonds.
- 💣 Avoid bombs to protect your lives.
- ❤️ Three lives to start with.
- ⏱️ 45-second game timer.
- 🏆 Score tracking and game-over screen.
- 🔄 Restart button to play again.
- 📱 Mobile-friendly controls.
- ⌨️ Keyboard controls for desktop users.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Open the live game link in your browser.
2. Click Start Game.
3. Move the basket using the arrow keys, on-screen buttons, or touch controls.
4. Catch the falling objects and avoid bombs.
5. Try to achieve the highest score!
